\# MediCore Analytics API



\## Overview



MediCore Analytics API provides data processing and analytics

for laboratory records and hospital appointments.



Built with Python and FastAPI, it reuses the data processing

module to validate records and generate analytical reports.



\## Technologies



\- Python 3.13

\- FastAPI

\- Uvicorn

\- Pydantic

\- Pytest

\- HTTPX



\## Features



\- Laboratory record validation and analysis

\- Appointment record validation and analysis

\- CSV sample data processing

\- Reference-range classification

\- Appointment status statistics

\- Average appointment duration calculation

\- Invalid record detection and error reporting

\- REST API

\- Interactive Swagger documentation

\- Automated tests
